# Typefaces

The skins' typefaces, kept here so the panel never loads anything from a third party. Each skin's stylesheet (`socket.css`, `display.css`, `home.css`) points at these files.

Only the Latin and Latin Extended subsets are kept: they cover English and Turkish. The files were downloaded from Google Fonts on 2026-11-22.
